Cost-sensitive machine learning for scikit-learn

Not every mistake costs the same.

Accuracy, F1 and AUC price a false positive and a false negative the same. Your business does not. Empulse lets you write down what each outcome is actually worth, then evaluate, train and threshold your models as scikit-learn estimators.

Get started → Work through the tutorial
$ pip install empulse

Python 3.11 or higher. Optional extras add additional functionalities for boosting and symbolic regression models.

A minute with Empulse

Four steps from a business question to a value-driven decision.

from empulse.metrics import CostMatrix

# Assign costs using business variables.
cost_matrix = (
    CostMatrix()
    .add_fp_cost('incentive')  # a wasted discount
    .add_fn_cost('clv')        # a lost customer
    .set_default(incentive=10, clv=200)
)

Define the cost matrix

Assign costs to false positives and false negatives using named variables or fixed amounts.

Evaluates to

CostMatrix(tp_cost=0, tn_cost=0, fp_cost=incentive, fn_cost=clv)

Named symbols allow costs to vary per customer.

Defining costs → 
from empulse.metrics import Cost, Metric

expected_cost = Metric(cost_matrix, Cost())

y_score = baseline.predict_proba(X_test)[:, 1]
expected_cost(y_test, y_score)

Turn it into a metric

A Metric wraps the cost matrix into a scikit-learn scoring function for cross-validation and grid search.

Evaluates to

10.22

Expected cost in euros per customer for the baseline model.

Measuring a model → 
from empulse.models import CSLogitClassifier

model = CSLogitClassifier(loss=expected_cost).fit(X_train, y_train)

expected_cost(y_test, model.predict_proba(X_test)[:, 1])

Train on the cost metric

Pass the metric directly as the training loss function.

Evaluates to

9.37

Expected cost drops to 9.37 euros per customer, an 8% reduction over the baseline on the same test data.

Training a model → 
from empulse.models import CSThresholdClassifier

decider = CSThresholdClassifier(estimator=model, loss=expected_cost)
decider.fit(X_train, y_train)

decider.threshold_

Find the optimal threshold

Find the decision threshold that minimizes expected cost for the trained model.

Evaluates to

0.048

The cost-optimal decision threshold is 0.048 instead of the default 0.5.
