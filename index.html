Cost-sensitive machine learning for scikit-learn

Optimize
for value,
not stats.

Accuracy, F1 and AUC price every mistake the same. Your business does not. Write down what each outcome costs, then evaluate, train and threshold your models for profit, with the scikit-learn API you already know.

$ pip install empulse
Get started →

Python 3.11 or higher. Optional extras add samplers and boosting models.

Quick tour

A minute with empulse.

Four scikit-learn steps from a business question to a decision that pays.

churn.py 
from empulse.metrics import CostMatrix

# Assign costs using business variables.
cost_matrix = (
    CostMatrix()
    .add_fp_cost('incentive')  # a wasted discount
    .add_fn_cost('clv')        # a lost customer
    .set_default(incentive=10, clv=200)
)
Out CostMatrix(tp_cost=0, tn_cost=0, fp_cost=incentive, fn_cost=clv) Named symbols allow costs to vary per customer. Defining costs → 
from empulse.metrics import Cost, Metric

expected_cost = Metric(cost_matrix, Cost())

y_score = baseline.predict_proba(X_test)[:, 1]
expected_cost(y_test, y_score)
Out 10.22 Expected cost in euros per customer for the baseline model. Measuring a model → 
from empulse.models import CSLogitClassifier

model = CSLogitClassifier(loss=expected_cost).fit(X_train, y_train)

expected_cost(y_test, model.predict_proba(X_test)[:, 1])
Out 9.37 Expected cost drops to 9.37 euros per customer, an 8% reduction over the baseline. Training a model → 
from empulse.models import CSThresholdClassifier

decider = CSThresholdClassifier(estimator=model, loss=expected_cost)
decider.fit(X_train, y_train)

decider.threshold_
Out 0.048 The cost-optimal decision threshold is 0.048 instead of the default 0.5. Making a decision →

Put a price on every outcome.

One cost matrix carries through evaluation, training and the final decision, so the model you ship is judged by the number your business reports.

Metrics that speak in euros

scikit-learn native

Fits where your models already live

Estimators, metrics and samplers follow scikit-learn's conventions, so they slot into the tools you already use: Pipeline, GridSearchCV, cross_val_score, and the rest of the ecosystem.

pipe = make_pipeline(
    StandardScaler(),
    CSLogitClassifier(loss=expected_cost),
)
cross_val_score(pipe, X_train, y_train)
