Getting Started#

New to Empulse? Start here.

Installation covers installing the package and its optional backends. Quickstart gets you from a fresh install to a model that makes money in about five minutes. Which tool do I need? maps out which part of the package you need for the problem you actually have.

Once you have the basics, the Tutorial works through a complete real-world case, and the User Guide covers each component in depth.
