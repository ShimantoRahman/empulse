===============
Getting Started
===============

New to Empulse? Start here.

:doc:`getting_started/installation` covers installing the package and its optional backends.
:doc:`getting_started/quickstart` gets you from a fresh install to a model that makes money in
about five minutes. :doc:`getting_started/overview` maps out which part of the package you need
for the problem you actually have.

Once you have the basics, the :doc:`tutorial` works through a complete real-world case, and the
:doc:`guide` covers each component in depth.
